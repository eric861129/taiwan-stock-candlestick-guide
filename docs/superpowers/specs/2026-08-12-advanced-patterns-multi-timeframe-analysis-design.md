## Problem Statement

目前網站能讓讀者輸入台股代碼並查看最近 60 根日 K，但自動比對器實際只辨識最後一至三根 K 棒的短窗型態。讀者想比較的頭肩頂、雙重頂、圓弧頂、三角收斂與箱型等圖形，必須觀察一段時間內的波峰、波谷、頸線、支撐與壓力，現有結果無法回答「最近完整走勢最接近哪一種價格結構」。

現有圖表雖標示價格與成交量單位，卻沒有可讀的數值刻度、日期刻度或完整型態疊線。即使系統說某個型態接近，初學者仍難以在圖上核對形成範圍、轉折點、確認條件與失效條件。

只看日 K 也會失去重要背景。月 K、週 K、日 K分別代表長期背景、中期結構與近期條件；目前每檔只保留 120 根日 K，最多只能聚合出約 26 根週 K與 6 根月 K，不足以進行真正的多時間週期判讀。原始價格又會因除權、除息、減資或分割產生機械跳空，若沒有可稽核的還原價格，長週期型態容易被誤判。

最後，現有型態卡沒有完整涵蓋常見價格結構與 TA-Lib Pattern Recognition Functions 的 61 種 K 棒型態。若直接把所有內容混在同一區域或同一排名，新手會難以理解不同時間尺度，重複卡片也容易出現兩套互相矛盾的定義。

## Solution

將股票分析器擴充為可解釋的多時間週期價格結構工具。資料工作預先建立官方原始與有證據的向後還原序列，日 K、週 K、月 K 各保留最多 120 根已完成 K 棒，畫面預設顯示最近 60 根。讀者先看月 K 長期背景，再看週 K 中期結構，最後用日 K 核對近期確認與失效；三個週期各自分析及排名，摘要只說明一致、部分一致、分歧或證據不足。

新增獨立的價格結構引擎，以轉折點、ATR、趨勢邊界、支撐壓力與可觀察規則辨識首批九種完整結構。每個週期只顯示零至三個真正通過門檻的候選，一次只把選中的候選畫到主圖。圖表補上價格、成交量與日期數值刻度，並顯示形成區間、轉折點、頸線、確認線與失效線。只有已確認型態可以顯示條件式情境區，而且必須明示它不是價格預測。

型態內容改為單一正規資料來源，再透過集合呈現在價格結構型態主館、K 棒型態速查館及獨立的 TA-Lib 進階 K 棒圖鑑。同一型態只維護一份定義與圖例；TA-Lib 官方清單的 61 個函式全部製作完整教學卡，但不因此全部加入自動排行。

## User Stories

1. As a 初學者, I want 輸入上市或上櫃普通股代碼, so that 我可以用真實台股資料練習。
2. As a 初學者, I want 先看到股票名稱、代碼、市場、資料截止日與價格模式, so that 我知道自己正在分析什麼資料。
3. As a 初學者, I want 先看到月 K、週 K、日 K 摘要, so that 我不會只看短期波動便下結論。
4. As a 初學者, I want 依月 K → 週 K → 日 K 的順序閱讀, so that 我能從長期背景走到近期條件。
5. As a 初學者, I want 知道三個週期是「一致、部分一致、分歧或證據不足」, so that 我能理解不同時間尺度可能給出不同訊息。
6. As a 初學者, I want 三個週期各自保留候選與分數, so that 我不會被不透明的綜合分數誤導。
7. As a 初學者, I want 日 K 預設展開, so that 我能快速查看較近期的觸發與失效。
8. As a 中長期讀者, I want 切換週 K 與月 K, so that 我能觀察中期結構及長期支撐壓力。
9. As a 讀者, I want 使用三週期比較畫面, so that 我能並列比較同一股票在不同時間尺度的輪廓。
10. As a 手機讀者, I want 三週期依月、週、日垂直排列, so that 我不用在狹窄畫面橫向縮放三張圖。
11. As a 桌機讀者, I want 圖表與候選卡雙欄顯示, so that 我可以一邊選型態、一邊看疊線。
12. As a 讀者, I want 圖上顯示 TWD 數值刻度, so that 我知道每個支撐、壓力與轉折點的實際價格。
13. As a 讀者, I want 圖上顯示成交量股數刻度, so that 我能理解量價背景而不是只看柱形高低。
14. As a 讀者, I want 圖上顯示日期刻度, so that 我知道型態形成與確認的時間範圍。
15. As a 讀者, I want 預設查看最近 60 根 K 棒, so that 圖表保持清楚且符合近期學習情境。
16. As a 讀者, I want 型態起點超出 60 根時能展開完整型態範圍, so that 我不會看到被裁切後的假完整輪廓。
17. As a 讀者, I want 每個週期最多看到三個通過門檻的候選, so that 我能比較合理替代解釋而不被大量低分結果干擾。
18. As a 讀者, I want 沒有型態成立時看到正式的「無明顯型態」, so that 我知道沒有答案也是有效結果。
19. As a 讀者, I want 外觀接近但未成立的項目放在次要教學區, so that 我能學習缺少條件又不把它誤認為候選。
20. As a 讀者, I want 一次只顯示一套型態疊線, so that 三個候選不會互相遮蓋。
21. As a 讀者, I want 在圖上看到實際形成區間, so that 我能核對系統使用了哪些 K 棒。
22. As a 讀者, I want 在圖上看到波峰、波谷與重要價位, so that 我能自行判斷輪廓是否合理。
23. As a 讀者, I want 在圖上看到頸線、支撐、壓力或趨勢邊界, so that 型態名稱能對應到可觀察結構。
24. As a 讀者, I want 清楚區分形成中、已確認、已失效與證據不足, so that 我不會把尚未完成的輪廓當成定案。
25. As a 讀者, I want 形成中的型態只顯示確認線與失效線, so that 我不會把可能路徑當成預測。
26. As a 讀者, I want 已確認型態才顯示條件式情境, so that 情境建立在已發生的確認條件上。
27. As a 讀者, I want 條件式情境同時呈現延續、回測與失效, so that 我不會只看到單一路徑。
28. As a 讀者, I want 每張候選列出「為什麼接近、還要確認、何時失效」, so that 我能照固定流程學習。
29. As a 讀者, I want 看到跨週期背景一致或衝突提示, so that 我能把短期型態放回長期背景。
30. As a 讀者, I want 較長週期不偷偷改變短週期分數, so that 規則符合度仍能被解釋與重現。
31. As a 讀者, I want 切換官方原始價格與向後還原價格, so that 我能查看實際成交價格並理解公司行動影響。
32. As a 讀者, I want 價格模式切換時圖表與結果一起重算, so that 我不會混用兩種價格口徑。
33. As a 讀者, I want 還原證據不足時仍能查看原始價格, so that 單一資料限制不會讓整檔股票完全不可用。

38. As a 讀者, I want 查看箱型、三角收斂、旗形、雙重頂底、頭肩頂底、假突破與圓弧頂, so that 我能學習常見完整價格結構。

## Implementation Decisions

### 1. 規格優先順序與產品語意

本規格是前置規格的增量擴充。若兩者衝突，以本規格取代三項舊邊界：分析週期從只有日 K 擴充為日／週／月；價格結構從只供教學擴充為首批九種自動比對；原本完全禁止的未來圖形改為只允許已確認型態的條件式情境區。盤中行情、機率預測、目標價及買賣建議仍維持排除。

正式用語採「價格結構型態」「規則符合度」「型態候選」「接近但未成立的教學參考」「條件式情境投影」與「多時間週期摘要」。介面不得使用「AI 預測」「勝率」「上漲機率」「必漲圖」「必跌圖」或「精確買賣點」。日 K 的正式定位是觀察較近期的觸發、失效與風險位置。

### 2. 資訊架構

搜尋成功後依序呈現股票身分與資料狀態、多時間週期摘要、目前週期詳細圖、候選條件檢查、三週期比較，以及相關教材。預設開啟日 K 與向後還原價格；還原價格不可用時降級為官方原始價格並顯示原因。

多時間週期摘要各自列出週期、截止日、可用根數、價格模式、主要背景與第一候選。摘要整體狀態只有「週期一致、部分一致、週期分歧、證據不足」，不產生多空總分或投票。

詳細區桌機採圖表與候選雙欄，手機採圖表、候選、條件檢查垂直排列。控制項包含日／週／月、向後還原／官方原始，以及最近 60 根／完整型態範圍。

每個週期只顯示零至三張通過門檻的結構候選。候選卡顯示名稱、規則符合度、確認狀態、形成範圍、一句主要理由及套用圖表操作。一次只能選擇一張候選。低於門檻但外觀接近的項目放入次要教學區，並列出缺少的必要條件。

三週期比較在桌機並排月、週、日三張摘要圖，在手機依月→週→日垂直排列。摘要圖只顯示第一候選的主要輪廓，不畫右側情境；點選後切換詳細區。

### 3. 單一型態內容與三個集合

每個型態使用穩定識別碼與唯一正規內容，再透過集合出現在「價格結構型態主館」「K 棒型態速查館」「TA-Lib 進階 K 棒圖鑑」。集合不是內容複本；同一型態的名稱、定義、圖例、來源、限制與自動比對狀態只能維護一份。

正規型態內容至少保存：

- 台灣繁體中文名稱、英文名稱、別名與穩定網址名稱。
- 所屬集合與型態種類。
- 最少及最多使用根數。
- 可觀察定義、背景、確認、失效、常見誤判與限制。
- SVG 圖例、替代文字與逐根說明。
- 來源註記、自動比對支援狀態及相關型態。
- TA-Lib 卡片另保存官方函式名稱。

完整卡片不得只翻譯函式名稱，也不得直接複製來源長文。內容需交叉查證後以台灣繁體中文重新表述。

### 5. 行情來源與新版快照

行情維持純靜態架構。TWSE、TPEx 官方歷史日行情用於首次十年基準；盤後日行情用於增量更新；上市櫃普通股清冊、公司行動、交易日曆、緊急休市及停復牌公告提供證券類型與證據。瀏覽器只讀取同源的 manifest 與指定股票資料，不直接呼叫交易所或第三方服務。

行情契約升級為 schema v4，與目前只有原始日 K 的 v3 隔離。每檔股票保存：

- 股票身分、市場、幣別、快照雜湊及截止日。
- 官方原始與向後還原兩種價格模式。
- 每個價格模式的日 K、週 K、月 K。
- 每個週期最多 120 根已完成 K 棒。
- 週 K、月 K 可另外保存一根形成中 K 棒。
- 公司行動、調整因子、官方未報價、停牌及來源證據。
- 價格模式可用狀態、資料起訖與警告。

實際發布格式可壓縮或共用重複欄位，但解析後必須保留完整領域語意。

### 6. 週 K、月 K 聚合

週 K 依台灣交易日曆的自然週聚合，月 K 依曆月聚合。開盤取期間第一個合法交易日，最高與最低取期間極值，收盤取期間最後一個合法交易日，成交量及可用成交筆數加總。固定五個交易日或二十個交易日不視為週 K、月 K。

資料截止日後若該週或該月仍有預期交易日，聚合結果保存為形成中 K 棒；只有截止日已是該期間最後一個官方交易日才移入完成序列。形成中 K 棒可以畫圖，不進入特徵、確認或候選排名。

若期間內至少有一根合法日 K，但某個預期交易日有官方未報價或停牌證據，聚合棒可以標成資料不完整供讀者查看，不得進入 matcher。整個期間沒有合法日 K 時不建立價格棒，只保存證據。恢復交易後，matcher 只使用最後一個不完整或缺少週期之後的連續合法尾段。新上市首週或首月的預期日期從上市日起算。

### 7. 向後還原價格

資料工作以官方前收、參考價、配股比率、分割或減資資料建立版本化調整證據。每筆證據必須包含生效日、類型、可重算價格因子、必要時的成交量因子、來源及查核日。

向後還原以目前價格尺度為基準，生效日前的 OHLC 套用其後所有調整因子的累積效果。現金股利只調整價格；股票股利、分割或減資在官方資料足以完整重建股數尺度時，同步調整成交量。

任何會影響價格連續性的公司行動若缺少必要參數、來源或可重算因子，官方原始序列仍可發布，受影響區間的向後還原分析則正式標成證據不足。系統不得自行移除看起來異常的跳空。

計算順序固定為逐日還原、驗證日序列、聚合週 K 與月 K。不能先產生週 K、月 K 後再套單一調整係數，否則公司行動發生在期間中間時會算錯最高與最低。

### 8. 十年基準、增量更新與原子發布

120 根月 K 約需十年日行情。首次基準是可續跑、可快取的獨立資料工作，依官方交易日曆逐日取得全市場歷史行情，避免逐股票逐月產生大量請求。每個成功市場與日期都寫入可驗證快取，中斷後只重試缺少日期。較晚上市股票自然保留較短歷史。

每日工作只取得上一個成功快照後缺少的官方交易日，更新受影響股票，重算目前週、目前月及公司行動影響的還原序列，再裁切各週期至 120 根。沒有新交易日時正常停止，不重新部署。

日、週、月、原始、還原、調整證據、manifest、provenance、內容雜湊與封存檔必須屬於同一快照。來源、雜湊、聚合一致性或市場截止日無法驗證時，整體更新失敗並保留上一版。可說明的個別股票還原證據不足可以發布，但該股票必須攜帶正式不可用狀態。

首次十年資料工作與 Pages artifact 建置分開，避免日常部署超時。發布資料達 400 MiB 時停止部署並重新評估壓縮、拆分或替代託管，不等到 GitHub Pages 1 GB 上限才處理。

### 9. 價格結構引擎模組

長結構與既有一至三根 K 棒 matcher 分開。系統建立五個清楚接縫：

1. 結構特徵擷取器輸出 ATR、平滑價格、帶索引日期的轉折點、趨勢線、區域、觸碰與壓縮。
2. 結構規則登錄表負責版本化規則族與門檻。
3. 結構 matcher 負責資料守門、逐條評估、狀態、固定排序與零至三候選。
4. 疊線建構器只把 matcher 結果轉成資料座標，不重新判斷型態。
5. 多時間週期協調器個別呼叫三個週期，再產生背景提示及摘要狀態。

短窗 K 棒 matcher 繼續運作，但結果移到可收合的輔助區。兩套引擎不共用排行榜，除非未來另有經核准的跨規則族校準。

### 10. 結構特徵與資料守門

每次分析使用指定週期、指定價格模式的最多 120 根完成 K 棒，不能使用形成中 K 棒或分析截止日之後資料。日期必須遞增且唯一，OHLC、成交量、來源精度與比較單位必須合法。公司行動、未報價與停牌依連續性規則切斷候選窗。

轉折點必須保留 bar index、日期、價格、波峰／波谷種類及 ATR 顯著程度。擷取器使用固定且版本化的 pivot 寬度、ATR 顯著門檻與最小間隔。價格採對數或 ATR 正規化，確保平移或合理倍率縮放不改變結果。

平滑只用來找候選轉折點；真正規則仍以原始 high、low、close 驗證。趨勢線輸出斜率、截距、觸碰點與 ATR 正規化殘差。所有門檻集中在版本化設定，不散落於畫面或教學文案。

### 11. 首批九種自動價格結構

1. **箱型／矩形區間**：上下邊界各至少兩次有效觸碰、邊界近水平、多數 K 棒在區間內；收盤有效突破任一邊界才確認。
2. **三角收斂**：至少兩個高點與兩個低點、上下邊界距離縮小、交點位於合理範圍；收盤突破任一邊界才確認方向。
3. **旗形整理**：明確旗桿後出現較小、受限且方向相反或橫向的整理通道；沿旗桿方向突破整理邊界才確認。
4. **雙重頂**：兩個相近高點、中間低谷深度及峰距通過門檻；收盤跌破中間低谷頸線才確認。
5. **雙重底**：兩個相近低點、中間高點高度及谷距通過門檻；收盤突破中間高點頸線才確認。
6. **頭肩頂**：高低高低高交替、頭高於兩肩、肩部相似度與間隔合格；收盤跌破兩低點形成的可傾斜頸線才確認。
7. **頭肩底**：低高低高低交替、頭低於兩肩、肩部相似度與間隔合格；收盤突破兩高點形成的可傾斜頸線才確認。
8. **假突破**：價格先有效越過已建立邊界，接著在限定根數內返回原區域；收盤返回且未立即重新突破時確認假突破。
9. **圓弧頂**：跨度足夠、平滑斜率由正轉平再轉負、向下曲率與殘差通過門檻；收盤跌破已建立支撐或弧形基準才確認。

頭肩頸線不限制水平；三角形形成中不預設方向；圓弧頂不要求完美拋物線。成交量只作輔助條件，缺少成交量不能由價格分數補足。

### 12. 計分、狀態與排序

每個規則族分成必要、背景、輔助與失效規則。必要條件未全數通過時不能成為候選；決定性失效規則成立時不列入目前候選。分數正規化為 0～100，名稱固定為規則符合度。

每個規則族使用經正反 fixture 校準的版本化最低門檻。排序依規則符合度、必要幾何完整度、資料完整度、穩定型態 ID 固定決勝。每個週期只取通過門檻的前三名，不補低分結果。

確認狀態固定為：

- **形成中**：形成條件成立，確認事件尚未發生。
- **已確認**：確認條件已由目前或更早的完成 K 棒成立。
- **已失效**：預先定義的失效條件成立，只在歷史解說或接近參考中呈現。
- **證據不足**：資料不足以判斷形成或確認。

每個歷史 cutoff 只可使用當日以前資料。後續資料加入後，不得把過去當時的形成中結果改寫成當時已確認。

### 13. 候選輸出與圖表疊線

每個候選至少輸出型態 ID、週期、價格模式、規則符合度、確認狀態、實際形成起訖、anchors、疊線、逐條規則、確認條件、失效條件、警告及 matcher 版本。

疊線使用 bar index／日期與價格資料座標，由圖表共用 K 棒 x 軸與價格 y 軸轉換。支援頸線與邊界線、多轉折輪廓、支撐壓力區、圓弧曲線、轉折 anchors、條件式情境帶及文字標籤。所有圖形必須裁切在圖區內，並用線型、圖樣與標籤避免只靠顏色表達。

只有已確認候選顯示右側條件式情境，包含適用的突破延續、回測確認邊界、返回原區間或型態失效。情境用方向帶、箭頭及條件文字，不標示精確未來日期、目標價、命中率或唯一曲線。圖上固定顯示「條件式情境，非價格預測」。形成中候選只畫確認線與失效線。

### 14. 多時間週期協調

月 K、週 K、日 K 依序個別分析，每個週期有自己的可用根數、截止日、零至三個結構候選、短窗觀察、價格模式與警告。切換週期時可記住該週期最後選擇的候選，但不得混用不同週期的 anchors 或疊線。

每個候選可以提供多頭、空頭、中性或未決的背景方向，用來和較長週期比較。跨週期輸出只有背景一致、部分一致、背景衝突或較長週期證據不足。提示不改變目前候選分數，不隱藏有效候選，也不產生交易動作。

切換官方原始與向後還原價格時，圖表 OHLCV、價格刻度、matcher 輸入、候選、疊線、公司行動標記與警告必須一起切換。快取識別必須包含快照雜湊、時間週期、價格模式及 matcher 版本。

### 15. 圖表與無障礙

主圖顯示價格 Y 軸數值與「價格（TWD）」、成交量 Y 軸數值與「成交量（股）」、代表性日期刻度及水平格線。刻度依資料範圍選擇合理小數及千分位；成交量刻度可縮寫，但 tooltip 與表格顯示完整股數。

預設顯示最近 60 根完成 K 棒，形成中的週 K 或月 K 以淡色與文字／圖樣標記附加在右側。候選起點早於可見範圍時顯示提示，並允許展開至最多 120 根的完整形成範圍。

SVG 說明必須列出週期、價格模式、候選、形成區間、主要 anchors、確認與失效條件。所有週期、價格模式與候選控制可用鍵盤操作，切換後由 aria-live 宣告。OHLCV 表格保留作為圖表替代，並顯示形成中及價格模式。

依既有核准，本次可以略過人工螢幕閱讀器 gate；鍵盤、ARIA、結構化表格及自動化無障礙測試仍為必要驗收。

### 16. 教材調整

新增同一股票、同一截止日的互動式多時間週期練習。讀者先只看月 K 記錄長期方向與關鍵區域，再看週 K 判斷中期結構是否呼應，最後看日 K 核對近期確認與失效，完成後才揭露三週期摘要。

既有週期、原始與還原價格、多時間週期、價格結構及型態速查內容增加直接入口與解讀提醒，不複製整張型態卡。所有價格結構卡補上月／週／日的解讀提醒，不宣稱某型態只適用單一週期。

### 17. 錯誤與降級

- 找不到代碼時說明未出現在目前 manifest，保留搜尋欄。
- 不支援證券時說明只支援上市櫃普通股。
- 行情落後兩個以上交易日時明示截止日，不稱為目前型態。
- 歷史不足時顯示實際根數，未達規則最低需求便不分析。
- 形成中週／月 K 可查看但不進入排名。
- 還原證據不足時保留原始價格，停用還原分析並列出缺少證據。
- 沒有候選時顯示「無明顯型態」，不使用系統錯誤語氣。
- 接近但未成立時列出缺少條件，放在次要教學區。
- 停牌或未報價保留官方證據，不補造 OHLC。
- 個股檔案格式或雜湊錯誤時拒絕分析並允許重試。
- 快照整體驗證失敗時不發布，保留上一個成功版本。

### 18. 交付順序與完成條件

實作依序完成正規型態模型、三個圖鑑內容、快照 v4、結構特徵、九種規則族、圖表互動、多時間週期摘要與教材、整合驗證及正式發布。畫面不得在資料與 matcher 契約未穩定前自行重算型態。

只有下列條件全部達成才算完成：

1. 上市與上櫃普通股可查詢日、週、月。
2. 每週期具原始價格；證據完整時具向後還原價格。
3. 每週期最多 120 根完成 K 棒並預設顯示 60 根。
4. 形成中的週／月 K 可見但不參與候選。
5. 首批九種結構皆有可解釋規則、正反案例與疊線。
6. 每週期只顯示零至三個通過門檻的候選，一次只疊一個。
7. 形成中與已確認有不同情境呈現，且沒有機率、目標價或買賣訊號。
8. 圖表具 TWD、股數與日期數值刻度。
9. 多時間摘要能分辨一致、部分一致、分歧及證據不足，且不改變個別分數。
10. TA-Lib 進階圖鑑具官方清單全部 61 張完整卡片，並和既有卡共用正規內容。
11. 新版快照、增量更新、原子回復及 400 MiB 容量 gate 通過。
12. 必要自動測試、建置、GitHub Pages 部署與公開站台驗證成功。

## Testing Decisions

### 測試原則與最高接縫

測試驗證外部可觀察行為，不鎖定私有 helper、內部迴圈或暫時檔案配置。優先使用三個最高接縫：

1. **行情快照黑箱契約**：以離線官方形狀 fixture 執行建立、增量、驗證及封存流程，檢查輸出的 v4 manifest 與股票資料。沿用目前 Python snapshot、source adapter 與 fixture 測試模式。
2. **多時間週期協調器**：輸入單一股票快照、價格模式與 cutoff，一次驗證月／週／日候選、狀態、背景提示及疊線。沿用目前 matcher 的 deterministic fixture 與 prefix 測試模式。
3. **完整股票分析頁**：掛載分析器或透過瀏覽器搜尋股票，驗證摘要、週期、價格模式、候選、圖表及錯誤狀態。沿用目前 Vue 元件測試與 Playwright 正式路徑測試。

圖鑑的 61 張卡片另以單一 catalog contract 測試驗證，不為每張卡建立一套重複 UI 測試接縫。

### 行情與聚合行為

- 自然週與曆月的開、高、低、收、成交量聚合。
- 連假、週末、月底、跨月、跨年及緊急休市。
- 本週、本月形成中及最後官方交易日完成判定。
- 新上市、短歷史、首週首月、停牌、未報價及零成交量。
- 公司行動發生在週中、月底、連續多事件與證據缺漏。
- 向後還原因子可由官方欄位重算，原始序列完全不被改寫。
- 先逐日還原後聚合的結果，以及直接調整聚合棒會失真的反例。
- v3 與 v4 不可混用，manifest、內容雜湊、provenance 與封存一致。
- 同截止日的增量更新結果與完整重建完全相同。
- 整體失敗保留上一成功快照，個股可說明的還原不足正確降級。

### 價格結構行為

每個首批規則族都要有明確成立、剛好通過、剛好不通過、外觀相近但關鍵條件缺少的案例，並涵蓋形成中、已確認、已失效與證據不足。

共用邊界測試包括價格平移、倍率縮放、平臺型 pivot、同價 pivot、零 ATR、單一尖峰、跳空、低流動性噪音、公司行動切窗及未調整跳空。每個 cutoff 使用資料 prefix，突破日以前不得標成已確認。排序要固定，回傳零至三候選且不補低分結果。

跨週期案例包含三週期一致、兩者一致、一致與衝突、某週期不足、三者都不足，以及較長週期提示不改變短週期分數。原始與還原價格使用分離的分析結果與快取識別。

### 圖表與元件行為

- TWD、股數及日期刻度映射與格式。
- 同價範圍、零／極大成交量、小數價格及短歷史。
- 頸線、輪廓、區域、圓弧、anchor、情境帶與標籤。
- 圖形裁切、唯一 SVG ID、響應式尺寸與資料座標。
- 一次只顯示一套候選疊線。
- 日／週／月、原始／還原切換後，圖表與結果使用相同資料。
- 形成中 K 棒不進入候選日期及分數。
- OHLCV 表格與主圖資料一致。

### 圖鑑契約

- TA-Lib 官方函式清單剛好 61 個且沒有重複或缺漏。
- 每張卡具備完整內容最低欄位。
- 穩定 ID、網址名稱、函式名稱與集合唯一。
- 重疊型態只存在一份正規內容。
- 每張圖例具有替代文字、來源與自動比對狀態。
- 名稱、別名、根數、方向、用途、集合及支援狀態篩選具決定性。

### 瀏覽器與部署行為

- 股票搜尋、多時間摘要、候選切換及完整型態範圍。
- 桌機雙欄、手機垂直閱讀及三週期比較。
- 鍵盤操作、焦點、aria-live 與表格替代。
- GitHub Pages 子路徑、直接網址及重新整理。
- 發布 artifact 小於 400 MiB。
- 正式網址回應成功，標題、canonical、資料截止日及指定股票完整流程正確。

## Out of Scope

- 未經多年歷史、無前視偏誤、樣本外回測及機率校準的上漲／下跌機率。
- 精確目標價、進出場價、買賣按鈕、下單整合或投資建議。
- AI、機器學習或不可解釋的影像分類模型。
- 盤中、分鐘 K、逐筆或即時行情。
- ETF、ETN、權證、興櫃、期貨、選擇權與加密貨幣。
- 把 TA-Lib 61 種型態全部加入主分析器自動排行。
- 由瀏覽器直接呼叫 TWSE、TPEx 或第三方行情服務。
- 任意歷史截止日回測器、策略損益、勝率或社群比較。
- 因三週期一致便自動產生單一預測路徑。
- 使用未完成週 K 或月 K 確認型態。
- 人工螢幕閱讀器 gate；自動化無障礙與鍵盤驗證仍在範圍內。
