# Triage Labels

工程 Skills 使用下列固定角色與 GitHub label 對應：

| Skill 角色 | GitHub label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待補充必要資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人工處理或決策 |
| `wontfix` | `wontfix` | 已決定不處理 |

當 Skill 使用角色名稱時，套用同名 GitHub label。
