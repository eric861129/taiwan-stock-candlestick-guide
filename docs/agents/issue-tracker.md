# Issue Tracker

本專案的規格與工作項目放在 `eric861129/taiwan-stock-candlestick-guide` 的 GitHub Issues，使用 `gh` CLI 操作。

## 慣例

- 建立、讀取、留言、標記與關閉工作項目時，使用對應的 `gh issue` 指令。
- Skill 要求「發布到 issue tracker」時，建立 GitHub issue。
- Skill 要求「讀取相關 ticket」時，讀取 issue 本文、留言及 labels。
- Pull request 不作為 triage 的需求入口。
- GitHub Issues 與 pull requests 共用編號空間，遇到不確定的編號時要先確認類型。
